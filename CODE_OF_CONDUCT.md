# Code of Conduct

This project is dedicated to providing a **welcoming, safe, and inclusive** environment for everyone, in line with guidance from [Project Include](https://projectinclude.org/writing_cocs#).

All participants in the SutraID community (maintainers, contributors, and users) are expected to follow this Code of Conduct in all project spaces: GitHub issues, pull requests, code review, discussions, and any other channels used for project communication.

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of:

- **Background**: age, body size, visible or invisible disability, ethnicity, caste, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.
- **Role**: whether you are a maintainer, core contributor, casual contributor, or user.

We are committed to building a project culture that is:

- **Inclusive and respectful**
- **Collaborative and supportive**
- **Focused on learning and improvement**

## Expected Behavior

- **Be respectful and considerate.** Assume good intent and engage with curiosity.
- **Use inclusive language.** Avoid slurs, stereotypes, or assumptions about identity or background.
- **Welcome different perspectives and experiences.**
- **Give and receive constructive feedback.** Focus on the code and ideas, not on individuals.
- **Respect boundaries and time.** Do not pressure others for immediate responses or free consulting.
- **Follow project processes.** Use issues and pull requests for technical discussion, not personal attacks.

## Unacceptable Behavior

Examples of unacceptable behavior include (but are not limited to):

- Harassment, discrimination, or exclusionary behavior of any kind
- Trolling, insulting or derogatory comments, personal or political attacks
- Public or private harassment, including repeated unwanted contact
- Publishing others’ private information (doxing) without explicit permission
- Sexualized language or imagery; unwelcome sexual or romantic attention
- Deliberate misgendering or use of rejected names
- Advocating for or encouraging any of the above behavior

## Reporting and Enforcement

If you experience or witness unacceptable behavior:

- **Prefer GitHub:** Open a confidential issue or use GitHub’s reporting tools where available.
- **Or contact maintainers directly:** If you prefer private reporting, you may contact the maintainers using the contact information in `SECURITY.md` or via the repository’s “Security” or “Contact” links.

When reporting, please include:

- What happened (with links/screenshots if possible)
- When and where it happened (issue/PR link, discussion, etc.)
- Any other context you think is relevant

### Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct. They may take appropriate and fair corrective action, including but not limited to:

- Asking for a public or private apology
- Moderating, editing, or removing comments, code, or other contributions
- Temporarily or permanently banning individuals from project spaces
- Escalating to platform support (e.g., GitHub Support) if necessary

Maintainers must:

- Consider context and impact
- Apply this Code of Conduct consistently
- Listen to and respect impacted people

## Scope

This Code of Conduct applies:

- Within all project repositories, issues, pull requests, and discussions
- In any public or private spaces where the project is being represented (e.g., conferences, community chats), when a person is officially representing the project
