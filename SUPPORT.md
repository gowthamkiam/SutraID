# Support Policy

SutraID is an open-source project maintained by the community.  
This document explains what kind of support you can expect and how to get help.

---

## Where to Get Help

- **GitHub Issues (primary channel)**
  - Bug reports
  - Feature requests
  - Documentation issues or improvements
  - Questions about configuration and usage (best-effort)

When opening an issue:

- Provide a clear description of the problem.
- Include environment details (OS, Node.js version, database version, Docker vs bare-metal).
- Add relevant logs or error messages (redacting any secrets).

---

## What You Can Expect

Because this is an open-source project:

- **No formal SLA.** There are no guaranteed response or resolution times.
- **Best-effort responses.** Maintainers and contributors will respond as time allows.
- **Community-driven fixes.** Many issues may be resolved by community pull requests.

We aim to:

- Triage new issues regularly.
- Prioritize:
  - Security vulnerabilities (see `SECURITY.md`)
  - Reproducible bugs that affect core functionality
  - Documentation gaps that block new adopters

---

## What Is Out of Scope

The project does **not** provide:

- Guaranteed uptime or hosting for your deployments.
- Dedicated 24/7 production support or on-call rotations.
- Custom feature development on demand.
- Legal, compliance, or regulatory advice.

For production deployments, you are responsible for:

- Choosing and operating your own infrastructure (e.g., Railway, Neon, Netlify, Kubernetes, etc.).
- Monitoring, alerting, backups, and incident response.
- Compliance with data protection and privacy regulations.

---

## Security and Vulnerabilities

If you believe you have found a security issue, **do not** open a public GitHub issue.  
Follow the private disclosure process described in **`SECURITY.md`**.

---

## Contributions Welcome

Support is a two-way street in open-source:

- If you discover a fix, consider opening a Pull Request.
- If you improve the documentation, please share your updates.
- If you’ve deployed SutraID successfully, sharing your setup can help others.

See **`CONTRIBUTING.md`** for details on how to contribute changes.
